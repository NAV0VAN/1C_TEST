# Куда копировать на рабочий ПК

Содержимое этой папки предназначено для:

```
F:\1С Аутсорсинг\Reinberg\Вспомогательные обработки\
```

Скопируйте сюда оба объекта (как у выгрузки из Конфигуратора):

- `СозданиеКоробочныхШтрихкодовНоменклатуры.xml`
- папку `СозданиеКоробочныхШтрихкодовНоменклатуры\`

Либо распакуйте архив `СозданиеКоробочныхШтрихкодовНоменклатуры_xml.zip` прямо в каталог на диске `F:`.

Затем в Конфигураторе: **Загрузить из файлов** → укажите `.xml` → сохраните `.epf` рядом с остальными вспомогательными обработками.
