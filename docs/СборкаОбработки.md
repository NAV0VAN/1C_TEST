# Загрузка из файлов (Конфигуратор)

Каталог `epf/` — иерархическая XML-выгрузка внешней обработки (формат платформы 8.3, version `2.17`).

## Через UI

1. Конфигуратор → **Файл → Новый → Внешняя обработка** (или откройте существующую).
2. В дереве обработки: ПКМ → **Загрузить из файлов…**  
   либо пункт меню загрузки внешней обработки/отчёта из файлов.
3. Выберите корневой файл:

`epf/СозданиеКоробочныхШтрихкодовНоменклатуры.xml`

4. **Файл → Сохранить как** → `СозданиеКоробочныхШтрихкодовНоменклатуры.epf`.

## Через командную строку

```bat
"%ProgramFiles%\1cv8\8.3.XX.XXXX\bin\1cv8.exe" DESIGNER /DisableStartupDialogs ^
  /LoadExternalDataProcessorOrReportFromFiles ^
  "C:\path\to\epf\СозданиеКоробочныхШтрихкодовНоменклатуры.xml" ^
  "C:\path\to\СозданиеКоробочныхШтрихкодовНоменклатуры.epf"
```

Обратная выгрузка `.epf` → файлы:

```bat
1cv8 DESIGNER /DumpExternalDataProcessorOrReportToFiles ^
  "C:\path\to\out" ^
  "C:\path\to\СозданиеКоробочныхШтрихкодовНоменклатуры.epf"
```

## Состав файлов

| Файл | Назначение |
|------|------------|
| `*.xml` (корень) | Метаданные обработки, `DefaultForm`, UUID |
| `Ext/ObjectModule.bsl` | Серверная логика S→B и дублей |
| `Forms/Форма.xml` | Метаданные формы |
| `Forms/Форма/Ext/Form.xml` | Элементы, реквизиты, команды |
| `Forms/Форма/Ext/Form/Module.bsl` | Модуль формы |

Не переименовывайте корневой XML и папку обработки — имена должны совпадать с `<Name>` в метаданных.
