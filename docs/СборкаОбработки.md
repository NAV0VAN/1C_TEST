# Сборка внешней обработки в Конфигураторе

Исходники — текст модулей. Бинарный `.epf` собирается в Конфигураторе (или EDT) на базе УНФ.

## 1. Создать обработку

1. Конфигуратор → **Файл → Новый → Внешняя обработка**.
2. Имя: `СозданиеКоробочныхШтрихкодовНоменклатуры`.
3. Синоним: `Создание коробочных штрихкодов номенклатуры`.

## 2. Модуль объекта

Открыть **Модуль объекта**, вставить содержимое:

`src/ВнешняяОбработка.СозданиеКоробочныхШтрихкодовНоменклатуры/ObjectModule.bsl`

## 3. Управляемая форма «Форма»

1. Добавить форму, имя `Форма`, тип — управляемая, назначить основной.
2. Реквизиты формы:

| Реквизит | Тип |
|----------|-----|
| `Объект` | данные объекта обработки (основной) |
| `ТолькоОтсутствующие` | Булево |
| `НадписьИтоги` | Строка (неограниченная / 200) |
| `ШтрихкодыКСозданию` | ТаблицаЗначений |

Колонки `ШтрихкодыКСозданию`:

| Колонка | Тип |
|---------|-----|
| `Выбран` | Булево |
| `БаночныйШтрихкод` | Строка (200) |
| `КоробочныйШтрихкод` | Строка (200) |
| `Номенклатура` | `СправочникСсылка.Номенклатура` |
| `Характеристика` | `СправочникСсылка.ХарактеристикиНоменклатуры` |
| `Партия` | `СправочникСсылка.ПартииНоменклатуры` |
| `ЕдиницаИзмерения` | тип измерения регистра в вашей УНФ |
| `Статус` | Строка (50) |
| `Комментарий` | Строка (500) |

3. Команды формы: `Заполнить`, `СоздатьШтрихкоды`, `ВыбратьВсеКСозданию`, `СнятьВсе` — обработчики с теми же именами в модуле формы.
4. Элементы:
   - флажок `ТолькоОтсутствующие`;
   - надпись `НадписьИтоги`;
   - таблица `ШтрихкодыКСозданию` со всеми колонками;
   - для `Выбран` — событие `ПриИзменении` → `ШтрихкодыКСозданиюВыбранПриИзменении`;
   - кнопки команд на командной панели.
5. События формы: `ПриСозданииНаСервере`, `ПриОткрытии`.
6. В модуль формы вставить:

`src/ВнешняяОбработка.СозданиеКоробочныхШтрихкодовНоменклатуры/Forms/Форма/Module.bsl`

## 4. Сохранить

Сохранить как `СозданиеКоробочныхШтрихкодовНоменклатуры.epf`.

## 5. Проверка дублей (smoke-тест)

1. В РС есть баночный `...#S#...`, коробочного нет → после **Заполнить** статус `КСозданию`.
2. **Создать штрихкоды** → появляется запись с `#B#`.
3. Повторный **Заполнить** / создание → `УжеЕсть` / пропуск дубля, вторая запись не создаётся.
4. Если коробочный ШК уже привязан к другой номенклатуре → `КонфликтДубля`, запись не создаётся.

## Замечания по версии УНФ

- Если в старой УНФ у регистра только измерение `Штрихкод`, а остальное — ресурсы, запись через `МенеджерЗаписи` обычно всё равно подходит; при ошибке записи сверьте состав измерений в метаданных.
- Имя справочника единиц (`ЕдиницыИзмерения` / `КлассификаторЕдиницИзмерения`) возьмите из измерения регистра вашей базы.
