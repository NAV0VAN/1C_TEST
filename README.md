# Создание коробочных штрихкодов номенклатуры (УНФ)

Внешняя обработка для `1С:УНФ`: по баночным ШК в `РегистрСведений.ШтрихкодыНоменклатуры` создаёт коробочные ШК по правилу сегмента упаковки **S → B**.

## Правило преобразования

| Вид | Пример |
|-----|--------|
| Баночный | `A#N#N#1#S#A#EC-B26B-3,75#20260305MO000000#20260305#N0000000` |
| Коробочный | `A#N#N#1#B#A#EC-B26B-3,75#20260305MO000000#20260305#N0000000` |

Сегменты через `#`, **5-й сегмент** (индекс 4): `S` = банка, `B` = коробка. Остальные сегменты и привязка к номенклатуре/характеристике/партии/ЕИ копируются без изменений.

## Проверка дублей ШК

Обработка **не записывает** коробочный ШК, если он уже есть:

1. **В регистре** — запрос по `Штрихкод = коробочный`:
   - та же номенклатура/характеристика/партия/ЕИ → статус `УжеЕсть` (дубль);
   - другая позиция → статус `КонфликтДубля` (занят).
2. **Внутри выборки** — несколько баночных дают один коробочный → статус `ДубльВВыборке`, автовыбор снимается.
3. **В пакете создания** — повтор того же коробочного ШК в одном запуске пропускается.
4. **При записи** — если конкурентно появился дубль, строка учитывается как пропуск по дублю, а не как «успех».

Строки со статусами дубля/конфликта нельзя отметить к созданию (кроме ручного разбора `ДубльВВыборке`).

## Состав исходников

```
src/ВнешняяОбработка.СозданиеКоробочныхШтрихкодовНоменклатуры/
  ObjectModule.bsl          — серверная логика (S→B, дубли, запись в РС)
  Forms/Форма/
    Module.bsl              — модуль управляемой формы
    FormSpec.xml            — спецификация реквизитов/команд формы
docs/
  СборкаОбработки.md        — пошаговая сборка .epf в Конфигураторе
```

## Быстрый старт

1. Соберите `.epf` по `docs/СборкаОбработки.md`.
2. В УНФ: **Файл → Открыть** (или подключите как дополнительную обработку).
3. **Заполнить** — отбор баночных `#S#`, расчёт коробочных, проверка дублей.
4. Отметьте нужные строки со статусом `КСозданию`.
5. **Создать штрихкоды** — запись в `РегистрСведений.ШтрихкодыНоменклатуры`.

## Требования

- УНФ с регистром `ШтрихкодыНоменклатуры` (измерения: `Штрихкод`, `Номенклатура`, `Характеристика`, `Партия`, `ЕдиницаИзмерения` — типовая схема с ~1.6.23+).
- Права на чтение/запись регистра.
- Тип ссылки `ЕдиницаИзмерения` уточните по своей версии УНФ при сборке формы.
