# Создание коробочных штрихкодов номенклатуры (УНФ)

Внешняя обработка в формате **XML-выгрузки для загрузки из файлов** в Конфигураторе 1С.

## Куда положить на диске F:

Готовый комплект для копирования:

```
Вспомогательные обработки\
  СозданиеКоробочныхШтрихкодовНоменклатуры.xml
  СозданиеКоробочныхШтрихкодовНоменклатуры\
```

Скопируйте в:

```
F:\1С Аутсорсинг\Reinberg\Вспомогательные обработки\
```

Архив для распаковки туда же: артефакт `СозданиеКоробочныхШтрихкодовНоменклатуры_xml.zip`.

> С облачного агента диск `F:` недоступен — копирование на `F:` выполняется на вашем ПК.

## Загрузка в Конфигураторе

1. Откройте Конфигуратор (платформа **8.3.8+**).
2. **Загрузить из файлов** → укажите:

```
F:\1С Аутсорсинг\Reinberg\Вспомогательные обработки\СозданиеКоробочныхШтрихкодовНоменклатуры.xml
```

3. Сохраните `.epf` в ту же папку (рядом с остальными вспомогательными обработками).
4. В УНФ: **Файл → Открыть** → `.epf`.

Командная строка:

```text
1cv8 DESIGNER /LoadExternalDataProcessorOrReportFromFiles ^
  "F:\1С Аутсорсинг\Reinberg\Вспомогательные обработки\СозданиеКоробочныхШтрихкодовНоменклатуры.xml" ^
  "F:\1С Аутсорсинг\Reinberg\Вспомогательные обработки\СозданиеКоробочныхШтрихкодовНоменклатуры.epf"
```

## Правило ШК

| Вид | Пример |
|-----|--------|
| Баночный | `A#N#N#1#S#A#EC-B26B-3,75#20260305MO000000#20260305#N0000000` |
| Коробочный | `A#N#N#1#B#A#EC-B26B-3,75#20260305MO000000#20260305#N0000000` |

5-й сегмент (`#`): **S → B**. Запись в `РегистрСведений.ШтрихкодыНоменклатуры`.

## Проверка дублей

- в регистре (`УжеЕсть` / `КонфликтДубля`);
- в выборке (`ДубльВВыборке`);
- в пакете создания;
- при конкурентной записи.

## Структура выгрузки

```
Вспомогательные обработки/          ← копировать на F:\...\Вспомогательные обработки\
  СозданиеКоробочныхШтрихкодовНоменклатуры.xml
  СозданиеКоробочныхШтрихкодовНоменклатуры/
    Ext/ObjectModule.bsl
    Forms/
      Форма.xml
      Форма/Ext/Form.xml
      Форма/Ext/Form/Module.bsl
epf/                                ← тот же комплект (исходник в репозитории)
```

## Использование

1. **Заполнить** — баночные `#S#`, расчёт коробочных, статусы дублей.
2. Отметить строки `КСозданию`.
3. **Создать штрихкоды** — запись без дублей.

Если при загрузке ругается на тип `ЕдиницаИзмерения`, сверьте имя справочника в измерении регистра вашей УНФ (`КлассификаторЕдиницИзмерения` / `ЕдиницыИзмерения`) и поправьте тип колонки в `Form.xml`.
